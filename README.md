## Sobre o projeto

O Vértice Imóveis é um website conceitual desenvolvido para representar uma imobiliária com presença digital moderna e profissional.

O projeto explora uma interface visual sofisticada, navegação intuitiva e adaptação para diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5 — Estrutura e organização do conteúdo
- CSS3 — Estilização, layout e responsividade
- JavaScript — Interatividade e comportamento da interface

## Objetivos

- Desenvolver uma interface comercial profissional
- Aplicar conceitos de design responsivo
- Trabalhar com elementos interativos
- Criar uma experiência consistente em dispositivos móveis e computadores
